# Boston House Price Prediction

Machine Learning Engineer Internship — Beginner Task.

## Objective

Build a regression model to predict Boston house prices using the provided housing dataset.

## Models Used

- Linear Regression
- Ridge Regression
- Random Forest
- Gradient Boosting

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Best Model

Gradient Boosting achieved the best performance among the tested models.

- MAE: 1.9187
- RMSE: 2.7024
- R² Score: 0.9004

## Conclusion

The project demonstrates a complete machine-learning regression workflow including data preprocessing, model training, model comparison, evaluation, prediction, and feature-importance analysis.
