# Machine Learning Engineer Internship

This repository contains the projects completed as part of my Machine Learning Engineer Internship.

## Projects

### 01. Boston House Price Prediction
A regression-based machine learning project for predicting Boston house prices using housing features.

**Models:** Linear Regression, Ridge Regression, Random Forest, Gradient Boosting

**Best R² Score:** 0.9004

### 02. Car Selling Price Prediction
A machine learning regression project for predicting the approximate selling price of used cars based on their features.

**R² Score:** 0.9621  
**MAE:** 0.6218  
**RMSE:** 0.9342

### 03. BERT Language Model for Sentiment Analysis
An NLP project demonstrating the implementation and evaluation of a pretrained BERT-based language model for sentiment analysis.

**Evaluation:** Accuracy, Precision, Recall and F1-score

The model achieved 1.00 on the 10 manually selected demonstration examples used in the notebook.
